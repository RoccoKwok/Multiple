# Introduction
This program, designed as a prototype for online classroom functionality, simulates the process of student file submission and administrator retrieval, similar to platforms like Google Classroom. This project serves as a training exercise to explore the mechanics of online learning environments.
You can continue editing the program by downloading the **.aia file**<br>
You can either download the **.abb or .apk file** to use the app directly.<br>
**REMEMBER! It can only be download via Android device.**
